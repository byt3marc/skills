# Password Creation Best Practices

Use this skill to guide users on creating secure, strong passwords.

## Core Rules

When advising on password creation, recommend:

1. **Length**: Minimum 12-16 characters (longer = stronger)
2. **Complexity**: Combine uppercase, lowercase, numbers, and symbols
3. **Passphrases**: Use memorable phrases like `Gato#Volador$2026!`
4. **Avoid**: Personal data, common words, patterns (`123456`, `qwerty`, `password`)

## Length: Why It Matters

Password strength increases exponentially with length:
- 8 characters: Can be cracked in hours with modern hardware
- 12 characters: Takes years to crack
- 16+ characters: Practically uncrackable with current technology

**Recommendation**: Aim for 14-20 characters for important accounts.

## Complexity: Building Blocks

### Character Types to Include
- **Uppercase**: A-Z (26 options)
- **Lowercase**: a-z (26 options)
- **Numbers**: 0-9 (10 options)
- **Symbols**: !@#$%^&*()_+-=[]{}|;:,.<>? (32+ options)

### Symbol Substitution Guide
| Letter | Substitution Options |
|--------|---------------------|

| E | 3, €, £ |
| I | 1, !, \| |
| O | 0, () |
| S | $, 5, § |
| T | 7, + |

## Passphrases: The Best Technique

### How to Create Strong Passphrases
1. Choose 3-4 unrelated words
2. Add numbers and symbols between them
3. Mix in capitalization

### Examples of Strong Passphrases
- `Gato#Volador$2026!` (Cat + Flyer + Year + Symbol)
- `Luna-Roja-Montaña@42` (Moon + Red + Mountain + Numbers)
- `Café&Libro#Estrella7` (Coffee + Book + Star + Number)

### Why Passphrases Work
- Easy to remember (visual story)
- Hard to brute-force (length)
- Not in any dictionary (combination)

## Techniques with Examples

### 1. Word Combination Method
Take unrelated words and add complexity:
- Base: `casa`, `perro`, `sol`
- Combined: `Casa#Perro$Sol!`
- With numbers: `Casa#Perro$Sol2026!`

### 2. Sentence Method
Take a memorable sentence and abbreviate:
- Sentence: "Mi gato negro come 3 pescados todos los viernes"
- Password: `MgNc3pTlV!`
- Enhanced: `MgNc#3pTlV!`

### 3. Pattern Method
Use a pattern you can remember:
- Pattern: `[Word][Symbol][Year][Number]`
- Example: `Trabajo#2026!42`
- Example: `Playa$2025#7`

### 4. Keyboard Pattern Method
Create patterns on the keyboard (avoid obvious ones):
- Weak: `qwerty`, `123456`
- Better: `Qw3rty!@#` (mixed case + symbols)
- Best: `1qaz@WSX` (diagonal pattern + symbols)

## Common Mistakes to Avoid

### 1. Personal Information
- Birthdays: `Juan1990!`
- Names: `Maria2025#`
- Pets: `MaxPerro$`
- Addresses: `Calle123!`

### 2. Common Patterns
- Sequential: `123456`, `abcdef`
- Repeated: `aaaaaa`, `111111`
- Keyboard: `qwerty`, `asdfgh`

### 3. Dictionary Words
- Single words: `password`, `monkey`, `dragon`
- Common phrases: `letmein`, `welcome1`

### 4. Short Passwords
- Under 8 characters: Crackable in minutes
- 8-10 characters: Crackable in hours/days
- 12+ characters: Much more secure

## Quick Checklist for Strong Passwords

✅ At least 12-16 characters
✅ Mix of uppercase and lowercase
✅ Contains numbers
✅ Contains symbols (!@#$%^&*)
✅ Not based on personal information
✅ Not a common word or pattern
✅ Unique for each account
✅ Memorable for you, hard for others

## When Advising Users

1. **Start simple**: Suggest passphrases first
2. **Add complexity gradually**: Add symbols and numbers
3. **Test memorability**: Ask if they can remember it
4. **Suggest variations**: Help them customize for different sites
5. **Recommend tools**: Suggest password managers for multiple accounts
